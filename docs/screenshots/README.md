# Screenshots

- `final/`: the finished site. Every page at 1280×800 (desktop) and 360×740 (phone),
  in the light and the dark theme, taken by the last check before handover.
- `m0-scaffold/`, `m1/`, `m3/`, `m3-editor/`, `m4/`, `m5/`, `m5-trace/`, `m6/`, `m7/`:
  taken during the build, at the end of each milestone. Some folders were taken again
  during the polish milestone (milestone 8); others still show an earlier look (for
  example, `m5-trace/` shows the trace table's chips before they grew to 14 px).
- Milestone 2 built the emulator and changed no page, so it has no folder: its checks
  were the unit tests and `npm run verify:native`.

`npm run screenshots` takes new ones from a running dev or preview server (see the
README in the project folder).
